# غرفة Company OS

غرفة تشغيل تفاعلية تعرض وكلاء Company OS والمشاريع المسندة إليهم والمهام والملفات والعلاقات بينهم بأسلوب دفتر حي مرسوم باليد. يظهر «عقار أوب» كمشروع نشط تحت مظلة Company OS.

## التشغيل

```bash
npm install
npm run dev
```
