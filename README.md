# غرفة وكلاء عقار أوب

صفحة ديمو تفاعلية تعرض الوكلاء والمهام والملفات والعلاقات بينهم بأسلوب مخطط حي مرسوم باليد.

## التشغيل

```bash
npm install
npm run dev
```

## فيديو Higgsfield

صدّر الفيديو باسم `agent-room-bg.mp4` وضعه داخل `public/`. تستخدم الصفحة صورة
`agent-room-bg.jpg` تلقائيًا إلى أن يصبح الفيديو جاهزًا.

Prompt الحركة موجود في `design/HIGGSFIELD-PROMPT.md`.
